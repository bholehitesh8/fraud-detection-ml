End-to-End Surveillance Pipeline

Modular architecture from financial payload ingestion to real-time ML inference and tamper-evident audit logging.

1. Multi-Currency Ingestion

Accepts ISO 4217 currency payloads (USD, EUR, INR, GBP, etc.). Automatically validates non-negativity and scales foreign values into baseline USD.

2. Feature Engineering

Computes derived financial indicators: error in balance calculation, account drain flags, balance delta, and one-hot encoded transfer channels.

3. Machine Learning Inference

The trained ExtraTrees ensemble evaluates transformed features, outputting an objective prediction label and continuous probability score.

4. Auditable SQLite Trail

Every decision is atomically stored in SQLite with masked account privacy (e.g. ******7890), indexed reference IDs, and full risk telemetry.
